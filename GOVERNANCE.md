# Governance

claviger is an open-source project. Maintainers guide its direction and review code.

## Roles

- **Users:** everyone who uses claviger.
- **Contributors:** people who submit issues, pull requests, translations or documentation.
- **Maintainers:** contributors with commit access (see [OWNERS.md](OWNERS.md)).
- **Project lead:** Ömer Faruk Ballı, who makes final decisions.

## Becoming a maintainer

Sustained, high-quality contributions and participation in code review.

## Decision making

Normal pull requests are decided by maintainers. Major changes (vault format, cryptography, permissions) are proposed in an issue and use lazy consensus with a 7-day feedback period. Security-sensitive changes also need a security review.

## Changing this document

Changes follow the same process as other proposals.

## Code of conduct

Everyone follows the [Code of Conduct](CODE_OF_CONDUCT.md).
